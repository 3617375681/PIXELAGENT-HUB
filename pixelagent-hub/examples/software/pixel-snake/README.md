# Pixel Snake

A compact offline snake game on a 20x20 canvas.

## Controls

- Arrow keys: change snake direction.
- Pause/Resume button: toggle between paused and running. Game starts paused.
- Restart button: reset score, snake, and food, then return to paused.

## Rules

- Eat the red food to grow and gain 1 point.
- Hitting the wall or your own body ends the game.
