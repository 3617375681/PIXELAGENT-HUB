# Software Studio（开发中）

当前已经能由 Manager 规划、Coder 生成实际文件，再由 esbuild 构建自包含的静态浏览器应用。编译失败最多返修三轮，所有尝试保留；成功提供本地预览和源码 ZIP。暂未接入控制台、项目后续修改和自动交互验收。

## 创建与试玩

在 `pixelagent-hub/` 安装依赖并配置本地 `.env` 的模型 provider：

```powershell
npm ci
npm run studio:create -- "制作像素贪吃蛇，包含方向键移动、暂停、计分和重新开始"
npm run studio:preview -- <上一步输出的项目UUID>
```

浏览器打开 `http://127.0.0.1:4175/`。预览只监听本机，可用 `STUDIO_PREVIEW_PORT` 改端口。Ctrl+C 停止预览；生成期间 Ctrl+C 取消模型请求。创建命令总上限八分钟。

产物位于 `records/software-studio/<UUID>/`：

- `project.json`：规划、模型信息、各轮代码和真实构建结果。
- `requirements.md`、`design.md`：需求及生成的计划。
- `v1/source/` 等：保留每次构建的原始源码。
- `v1/build-report.json` 等：真实编译错误或成功结果。
- 成功版本的 `dist/index.html`：无需安装的自包含页面。
- `source.zip`：源码、预览、构建报告和运行说明。

生成失败、超时或取消时返回失败状态，不输出可交付包。构建成功标为 `ready_for_review`，不自动标为验收通过。支持 HTML/CSS/JS/Markdown 文件，暂不支持 imports、npm 依赖、外部素材和服务端。工具不执行模型生成的 shell 或安装脚本。

## 成熟度验收清单

- [x] 真实模型生成文件、真实编译、构建失败返修、源码 ZIP。
- [x] 独立本地预览；路径与资源限制；模型取消、失败记录。
- [ ] 控制台创建项目、显示阶段、加载源码、试玩、下载。
- [ ] 测试员依据需求实际操作浏览器，记录截图、运行错误和交互检查。
- [ ] 按交互失败证据返修；人工确认前不得显示已交付。
- [ ] 在同一个项目追加需求，保存版本、差异、回滚与验证记录。
- [ ] 重启后恢复项目和任务；取消、超时、断网不留下假成功。
- [ ] 至少五个固定应用案例与单 Agent 对照，公布成功率、耗时、成本和返修结果。
- [ ] 从干净克隆完成安装、运行和导出；CI、配置说明及发布文档齐全。

这些条目完成前，项目仍是原型。浏览器验收记录与构建报告分开保存，不把“模型说通过”当作工具测试。
