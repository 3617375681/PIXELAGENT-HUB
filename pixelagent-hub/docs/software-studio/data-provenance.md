# 展示与导出的数据来源

`/archive` 来自仓库内的模拟工作流。入口名为 **DEMO ARCHIVE**，页面常驻说明其中发布、测试和完成状态都是示例，并提供 `/live` 的真实记录入口。模拟数据保留用于展示布局，不能用于项目成功率、测试覆盖率或交付证明。

首页未运行时是空工作区。加载 Records API 会话后，工作流保存来源信息：`records-api` 表示从会话映射得到；实际输出 metadata 含 `llmProvider: mock` 或 `generatedBy: mock` 时标为 `mock`。识别对象字段而非正文字符串，讨论 mock 的文字不会被当成模拟执行。该信息只是记录来源，不能认证模型调用真实性。

导出面板显示来源说明。JSON 新增 `source`（`records-api` / `mock` / `empty` / `unknown`）、`sessionId`（有效会话来源才填写）和 `acceptance: not_verified`；Markdown 同样标注来源、会话 ID 及验收边界。旧消息、完成状态和模型评审文字保留，但不被提升为工具测试、部署或人工批准。当前演示开关控制下一次请求，不能改变已加载会话的来源。

这些是前端执行记录导出，Studio 的人工验收仍使用独立、按版本保存的决定。来源缺失时显示未确认，不猜测“真实生成”。
