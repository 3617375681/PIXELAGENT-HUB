# Requirements

A pixel color palette generator: show 5 color swatches with their hex codes, a Generate button for a new harmonious palette, and a lock toggle on each swatch to keep it.



Create an offline browser app using only HTML, CSS and plain JavaScript. Include root index.html and a README.md. No imports, packages, network requests, external assets, iframes or server code. Draw graphics with CSS or canvas. Use addEventListener instead of inline HTML event handlers. Keep the implementation concise. Provide keyboard-accessible labeled controls. Files must use relative paths and .html/.css/.js/.md extensions. Make it look finished: a centered card or game board on a themed background, one cohesive palette of 3–5 colors, system fonts at 16px or larger, clear visual hierarchy and generous spacing, visible hover, focus and pressed states on controls, and a layout that works from 360px wide. Styling never overrides required IDs, text or behavior.

Browser acceptance is pending.
