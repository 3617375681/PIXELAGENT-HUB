# Dashboard 按需加载验证

日期：2026-10-08。基线为 `81b7dab` 使用的 Dashboard 构建；优化保留全部页面与语法高亮语言支持，只改变模块加载时机。

## 改动

路由页面通过 React lazy/Suspense 加载，切换时提供可读的工作区加载状态。代码高亮模块在实际出现多行或带语言标记的代码块时才加载，等待期间显示原始代码，复制按钮仍使用同一完整文本。归档页的 KaTeX 与字体无需随普通首页一起加载。

## 构建证据

`npm run build -- --manifest` 生成依赖清单，沿入口和 Home 的静态 imports 去重累计 JavaScript 文件，排除 dynamicImports。gzip 数据为每个文件单独压缩后求和：

| 范围 | 原始字节 | gzip 字节 |
| --- | ---: | ---: |
| 优化前单一入口 | 1,662,682 | 530,069 |
| 优化后入口 | 234,386 | 75,242 |
| 优化后入口 + 首页静态依赖 | 661,468 | 205,307 |

首页静态 JavaScript 体积减少约 60%，gzip 减少约 61%。清单确认首页静态依赖不包含 CodeHighlight 或 ArchivePage。语法高亮仍是约 626 KB 的独立模块；包含代码块的会话会加载它，构建的大 chunk 提示仍保留。

这些是编译资产大小，不是实测网络传输量、首次内容显示时间或交互延迟；不包含 CSS、字体和 API 数据，也不能保证所有页面有相同比例改善。

Dashboard 类型检查、10 项测试及生产构建通过。用 Vite preview 打开生产构建，实际验证首页加载、Studio、归档、LIVE、OPS 的导航与返回，未执行付费生成。尚未单独验证高亮模块下载失败、旧缓存部署切换或慢网下的加载体验。
