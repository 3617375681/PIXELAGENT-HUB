# ADR 001：独立保存人工验收决定

状态：已实现。日期：2026-10-08。

## 需求与选择

构建成功和客户端检查均不足以批准作品。采用每个项目版本独立、追加保存的人工决定，关联当前预览及不可变诊断，而不是把生成状态改成 `approved` 或修改编译证据。

通过需操作者显式确认、填写说明并选择最新干净诊断。新诊断使旧批准失效；新派生版本需要独立验收。历史、源码及 ZIP 保留，失败记录可继续走返修流程。

## 取舍与边界

复用本地 JSON 文件和现有 API 鉴权，避免为个人项目新增数据库及账号系统。原子写入避免半截记录；读取失败显式报错。此实现适用于当前本地个人工作室，没有提供多进程并发审阅事务或认证审阅者身份。

人工决定来自持有 API 权限的客户端声明，不能证明真人身份或实际试玩。客户端诊断同样不是独立可信测试证据；生成页面在隔离 iframe 内不能调用此验收 API。后续独立浏览器 QA 和真实案例基准仍需完成。
